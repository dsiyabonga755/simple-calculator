# Simple Calculator (Python)
A simple calculator application built using Python that performs basic arithmetic operations through clean and functional interface.

## Features
- Addition, subtraction, multiplication, division
- Handles user input dynamically
- Simple and easy to use interface 
- Fast and lightweight

## Built With
- Python

## Project Structure
simple-calculator/
|-- SimplePythonCalculator.py

## How to Run
1. Make sure you have Python installed

2. Clone the repository:

   git clone https://github.com/dsiyabonga755/simple-calculator.git

3. Navigate into the folder:
   
   cd simple-calculator

4. Run the program:

   SimplePythonCalculator.py
